## 📜 About this repo

This is my public learning log. No fixed schedule, no guilt for missed days — just consistent, honest progress tracked one session at a time.

### Rules I'm playing by:
- **A "session"** = any day I engage with learning and commit something (notes, code, a fixed bug, a small project).
- **Multiple commits in one day** still count as 1 session — quality of engagement over spammy commits.
- **Missing a day** resets the streak, not the mission. I log why, and move on.
- **Every level ends with a small project** — not just tutorial notes.
